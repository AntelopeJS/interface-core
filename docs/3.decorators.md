## Overview

These factories build a new decorator. Using an existing one, such as `@Get`, does not need them. The callback receives the decorated target first and the arguments of the decorator call after it.

The factories build TypeScript legacy decorators, which need the `experimentalDecorators` compiler option. They do not implement the standard JavaScript decorator context API. Examples that call `Reflect.defineMetadata` also need `import "reflect-metadata"` first. Importing the package root already loads it.

[`MakeClassDecorator`](#makeclassdecorator) is the one-target starting point. The combined factory table matters only when one decorator must support several targets.

## Name a class with a decorator

This decorator stores a label when the class is declared. `target` is the class constructor, and `name` is the value passed to `@Label`.

```ts docs-check
import { MakeClassDecorator } from "@antelopejs/interface-core/decorators";

const labels = new WeakMap<Function, string>();
const Label = MakeClassDecorator((target: Function, name: string) => {
  labels.set(target, name);
});

@Label("users")
class UserController {}

const label = labels.get(UserController); // "users"
```

The factories run nothing at request time. The integration that uses them decides when to read stored values or call a decorated method.

```ts
import {

```

## Types

The module exports these types:

| Type                 | Description                                                  |
| -------------------- | ------------------------------------------------------------ |
| `Func<A, R>`         | Generic function type with arguments `A` and return type `R` |
| `Class<T, A>`        | Class constructor that creates instances of type `T`         |
| `DecoratorTarget`    | Target of a member or parameter decorator                    |
| `ClassDecorator<C>`  | Decorator applied to class constructors                      |
| `PropertyDecorator`  | Decorator applied to class properties                        |
| `MethodDecorator`    | Decorator applied to class methods and accessors             |
| `ParameterDecorator` | Decorator applied to method parameters                       |

In `Class<T, A>`, `T` defaults to `object`, so a bare `Class` promises no instance members. A member or parameter decorator receives a `DecoratorTarget`. It is the class prototype for an instance member, and the class itself for a static member or a constructor parameter. Its `constructor` is typed `Function`, so narrow it before you use it as a class.

## Single-target decorator factories

### `MakeClassDecorator`

Creates a decorator factory that targets classes. The handler receives the decorated class as its first argument, followed by the factory parameters. Its second type parameter, `C`, is the class type the handler receives and defaults to `Class`. A factory annotated with `ClassDecorator<Class<Table>>` hands its handler a `Class<Table>`.

```ts
import { MakeClassDecorator } from "@antelopejs/interface-core/decorators";

const Entity = MakeClassDecorator((target: Function, tableName: string) => {
  Reflect.defineMetadata("table", tableName, target);
});

@Entity("users")
class User {
  name!: string;
}
```

### `MakePropertyDecorator`

Creates a decorator factory that targets properties. The handler receives the target object and the property key, followed by the factory parameters.

```ts
import { MakePropertyDecorator } from "@antelopejs/interface-core/decorators";

const Column = MakePropertyDecorator((target, key, columnName: string) => {
  const columns = Reflect.getOwnMetadata("columns", target) || [];
  columns.push({ key, columnName });
  Reflect.defineMetadata("columns", columns, target);
});

class User {
  @Column("user_name")
  name!: string;
}
```

### `MakeMethodDecorator`

Creates a decorator factory that targets methods and accessors. The handler receives the target object, the method key, and the property descriptor, followed by the factory parameters.

```ts
import { MakeMethodDecorator } from "@antelopejs/interface-core/decorators";

const Log = MakeMethodDecorator((_target, key, descriptor, level: string) => {
  const original = descriptor.value;
  descriptor.value = function (...args: unknown[]) {
    console.log(`[${level}] Calling ${String(key)}`);
    return original.apply(this, args);
  };
});

class Service {
  @Log("info")
  process() {
    // ...
  }
}
```

### `MakeParameterDecorator`

Creates a decorator factory that targets method parameters. The handler receives the target object, the method key, and the parameter index, followed by the factory parameters.

```ts
import { MakeParameterDecorator } from "@antelopejs/interface-core/decorators";

const Inject = MakeParameterDecorator((target, key, index, token: string) => {
  if (typeof key === "number") return;
  const injections = Reflect.getOwnMetadata("injections", target, key) || [];
  injections[index] = token;
  Reflect.defineMetadata("injections", injections, target, key);
});

class Controller {
  handle(@Inject("db") db: any) {
    // ...
  }
}
```

## Multi-target decorator factories

For a decorator that applies to several targets, the module provides combined factories. A combined factory passes on the arguments TypeScript gives the decorator and does not detect the target itself. The handler tells the targets apart from those arguments, for example from an `undefined` key or descriptor.

| Factory                                              | Targets                                      |
| ---------------------------------------------------- | -------------------------------------------- |
| `MakePropertyAndClassDecorator`                      | Properties and classes                       |
| `MakeMethodAndClassDecorator`                        | Methods and classes                          |
| `MakeMethodAndPropertyDecorator`                     | Methods and properties                       |
| `MakeMethodAndPropertyAndClassDecorator`             | Methods, properties, and classes             |
| `MakeParameterAndClassDecorator`                     | Parameters and classes                       |
| `MakeParameterAndPropertyDecorator`                  | Parameters and properties                    |
| `MakeParameterAndPropertyAndClassDecorator`          | Parameters, properties, and classes          |
| `MakeParameterAndMethodDecorator`                    | Parameters and methods                       |
| `MakeParameterAndMethodAndClassDecorator`            | Parameters, methods, and classes             |
| `MakeParameterAndMethodAndPropertyDecorator`         | Parameters, methods, and properties          |
| `MakeParameterAndMethodAndPropertyAndClassDecorator` | Parameters, methods, properties, and classes |

### Example: method and class decorator

```ts
import { MakeMethodAndClassDecorator } from "@antelopejs/interface-core/decorators";

const Track = MakeMethodAndClassDecorator(
  (target, key, descriptor, category: string) => {
    if (descriptor) {
      // Applied to a method
      const original = descriptor.value;
      descriptor.value = function (...args: unknown[]) {
        console.log(`[${category}] ${String(key)} called`);
        return original.apply(this, args);
      };
    } else {
      // Applied to a class
      Reflect.defineMetadata("trackCategory", category, target);
    }
  },
);

@Track("api")
class ApiController {
  @Track("endpoint")
  getUsers() {
    // ...
  }
}
```

On a class, the `key` and `descriptor` arguments are `undefined`. On a method, all three arguments are set.
