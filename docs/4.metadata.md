## Overview

`GetMetadata` stores metadata on objects through the `reflect-metadata` library. It returns the metadata instance of a target, creates it on first use, and can inherit values through the prototype chain.

## Store a value on a target

A metadata class carries a unique symbol. `GetMetadata` returns its instance for the target. Later calls for that target return the same object, so there is no separate save step.

```ts docs-check
import { GetMetadata } from "@antelopejs/interface-core";

class LabelMetadata {
  static key = Symbol("LabelMetadata");
  label = "";
  constructor(_target: object) {}
}

class UserController {}
const metadata = GetMetadata(UserController.prototype, LabelMetadata);
metadata.label = "users";
const same = GetMetadata(UserController.prototype, LabelMetadata);
// same === metadata; same.label === "users"
```

The constructor and its prototype are different targets, so use one of them consistently. The [inheritance example](#inheritance) copies a parent's collection without sharing mutable state.

## Import

```ts
import { GetMetadata } from "@antelopejs/interface-core";
```

## `GetMetadata`

```ts fragment
function GetMetadata<
  T extends Record<string, any>,
  U extends Record<string, any>,
>(target: U, meta: Class<T, [U]> & { key: symbol }, inherit?: boolean): T;
```

### Parameters

| Parameter | Type                              | Default | Description                                          |
| --------- | --------------------------------- | ------- | ---------------------------------------------------- |
| `target`  | `U`                               | None    | The object to retrieve or create metadata for        |
| `meta`    | `Class<T, [U]> & { key: symbol }` | None    | A metadata class with a static `key` symbol          |
| `inherit` | `boolean`                         | `true`  | Whether to inherit metadata from the prototype chain |

### Return value

Returns the metadata instance of type `T` associated with the target.

## Define a metadata class

A metadata class has a static `key` property, a `Symbol`, and takes the target object as its constructor argument.

```ts
class RouteMetadata {
  static key = Symbol("RouteMetadata");

  public routes: Map<string, string> = new Map();

  constructor(_target: object) {
    // Initialize metadata for the target
  }
}
```

## Retrieve metadata

```ts fragment
import { GetMetadata } from "@antelopejs/interface-core";

class UserController {
  getUser() {}
  listUsers() {}
}

const meta = GetMetadata(UserController.prototype, RouteMetadata);
meta.routes.set("getUser", "/users/:id");
meta.routes.set("listUsers", "/users");
```

Repeated calls with the same target and metadata class return the same instance. `GetMetadata` stores it on the target with `Reflect.defineMetadata`.

## Inheritance

When `GetMetadata` creates metadata and `inherit` is `true`, the default, it first gets or creates the metadata of the target's prototype, and so on up the chain. If the metadata class defines an `inherit` method, that method receives the parent metadata. Otherwise `GetMetadata` copies a parent property only where the child has no own property of that name. So a child array initialized to `[]` keeps the default copy from taking the parent's array.

```ts
import { GetMetadata } from "@antelopejs/interface-core";

class ControllerMeta {
  static key = Symbol("ControllerMeta");

  public middleware: string[] = [];

  constructor(_target: object) {}

  inherit(parent: ControllerMeta) {
    this.middleware = [...parent.middleware];
  }
}

class BaseController {}
const baseMeta = GetMetadata(BaseController.prototype, ControllerMeta);
baseMeta.middleware.push("auth");

class AdminController extends BaseController {}
const adminMeta = GetMetadata(AdminController.prototype, ControllerMeta);
// adminMeta.middleware contains ["auth"] (inherited from BaseController)

adminMeta.middleware.push("adminOnly");
// adminMeta.middleware is now ["auth", "adminOnly"]
// baseMeta.middleware remains ["auth"]
```

Without an `inherit` method, `GetMetadata` makes a shallow copy of the parent's properties, listed by `Object.getOwnPropertyNames`, for each key that is not an own property of the child instance.

## Disable inheritance

`false` as the third argument skips the prototype chain:

```ts fragment
const meta = GetMetadata(target, RouteMetadata, false);
```

The flag affects creation only. It does not remove inherited values from an instance that already exists, and a different value on a later call does not rebuild the metadata.
