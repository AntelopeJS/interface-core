## v0.4.0

- **`InterfaceToImpl<T>` is exported.** It was already in the published declarations as the private alias that `ImplementInterface` names. A host can now type an implementation by its interface declaration ([#65](https://github.com/AntelopeJS/interface-core/pull/65)).
- **`ImplementInterface` accepts declarations typed with `interface`.** The declaration constraint widens from `T extends Record<string, unknown>` to `T extends object` in both overloads, so a declaration without an index signature can be passed. Every call that compiled before still compiles, and the runtime is unchanged ([#65](https://github.com/AntelopeJS/interface-core/pull/65)).
- **Decorator targets, `Class` and log arguments are typed (types only).** Member and parameter decorators (`PropertyDecorator`, `MethodDecorator`, `ParameterDecorator`) take the new `DecoratorTarget` instead of `any`: an object whose `readonly constructor: Function` is the function that built it. A consumer that read `target.constructor` as a class must narrow it. `Class<T = object>`: a bare `Class` no longer promises instance members, so a consumer that read them must name the instance type. `MakeClassDecorator<T, C extends Class = Class>` hands its handler the class type the factory is annotated with, and existing annotated factories compile unchanged. `Logging.*` and `Channel.*` take `...args: unknown[]`, and `Log.args` is `unknown[]`. No runtime change ([#62](https://github.com/AntelopeJS/interface-core/pull/62)).
- **`ImplementInterface` refuses a provider that lacks a handler named like an `Object.prototype` member.** When an interface declares a key such as `constructor`, `toString`, `hasOwnProperty`, `valueOf`, `isPrototypeOf`, `toLocaleString` or `propertyIsEnumerable`, and the implementation has no handler under it, `ImplementInterface` now fails with `Missing or malformed interface handler at implementation.<key>.` Before, it attached the inherited function, which answered garbage or failed at call time, and the provider's other functions were attached. A code search of the org found no interface that declares such a name ([#58](https://github.com/AntelopeJS/interface-core/pull/58)).
